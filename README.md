# Team Room Community

**Claude Code и Codex в одном рабочем пространстве. На вашем сервере.**

Чаты, память проекта и рабочие файлы доступны с компьютера и телефона. Задачи выполняются на подключённом компьютере, который вы выбираете сами.

[Сайт и демонстрация](https://iintuziasty-web.github.io/team-room/) · [Подробная установка](docs/INSTALL.md) · [Как устроена изоляция](docs/ISOLATION.md) · [Безопасность](SECURITY.md)

## Статус выпуска

**Community preview для самостоятельного размещения.** В комплекте исходники, инструкция и базовые автоматические проверки. Готового общего сервиса и подписанного установщика под чужой сервер нет. Реальные подписки, обе архитектуры Mac и физический iPhone требуют отдельной проверки на вашей установке.

[Результаты проверки](docs/QUALITY.md) · [Изменения](CHANGELOG.md) · [Участие в разработке](CONTRIBUTING.md) · [Передача репозитория и выпуск](docs/MAINTAINERS.md)

## Что умеет

- Продолжать разговор с Claude Code или Codex с историей, файлами и краткой памятью проекта.
- Выбирать компьютер для выполнения задач, подключать несколько компьютеров и аккаунтов провайдеров.
- Работать в нескольких сессиях, открывать два чата рядом, видеть агентов и запросы подтверждения.
- Дополнять запрос во время работы, смотреть файлы и HTML-превью.
- Использовать личную доску: «В работе», «Требует внимания», «Готово», заметки, закрепление и архив.
- Импортировать локальные сессии по явному действию пользователя.
- Использовать мобильный веб-интерфейс, голосовой ввод и уведомления при настройке соответствующих компонентов.
- Подключать общие MCP и скиллы; автоматическое обнаружение в новой установке выключено.

## Начать локально

Нужен **Node.js 22.9 или новее**.

```sh
git clone https://github.com/iintuziasty-web/team-room.git
cd team-room
npm ci
npm run setup
npm start
```

Откройте **http://127.0.0.1:4173**. Код первоначальной настройки находится в созданном локально файле `.env`, в поле `TEAM_ROOM_SETUP_TOKEN`. Создайте своё имя и пароль. Никакого общего аккаунта или предустановленной базы в проекте нет.

Сервер по умолчанию работает как хаб. Для запуска модели добавьте компьютер через «Компьютеры», скачайте **свой** пакет подключения и авторизуйтесь в **своих** Claude Code / Codex. Веб-вход в пространство и входы в провайдеров — отдельные действия.

## Сервер для телефона и нескольких компьютеров

Нужны собственный сервер, постоянное хранилище и HTTPS. Вариант с Docker Compose и Caddy:

1. Выполните `npm run setup`.
2. В `.env` задайте `TEAM_ROOM_DOMAIN` и `PUBLIC_URL=https://ваш-домен`; код настройки оставьте уникальным.
3. Направьте DNS на сервер и запустите `docker compose up -d --build`.
4. Откройте свой домен и завершите первичную настройку.

Папка данных находится в отдельном Docker volume. Делайте резервные копии. Railway также поддерживается: создайте **новый проект**, volume `/data` и собственные переменные окружения; см. [инструкцию](docs/INSTALL.md).

## Приложение Mac

Исходники включены. Сборка требует macOS и Xcode Command Line Tools. В сборку нужно явно передать адрес **своего** хаба:

```sh
TEAMROOM_HUB_URL=https://your-hub.example npm run build:mac
```

Получится `Team Room Community.app`. Приложение использует отдельные папки и фоновые службы Community. Комплект не содержит готовых аккаунтов, пар, ключей обновления или адреса чужого сервера. Инструкции по подписи и собственным обновлениям: [INSTALL.md](docs/INSTALL.md).

Для iPhone проще всего открыть свой HTTPS-сайт в Safari и добавить его на экран «Домой». Исходники iOS также доступны; установка нативного приложения требует самостоятельной сборки и подписи Apple.

## Данные и ограничения

- Каждая установка создаёт собственных пользователей, токены компьютеров, шифровальные ключи и push-ключи. Серверы не объединяются автоматически.
- Сессии одного пространства доступны его участникам согласно интерфейсу продукта. Это общий рабочий сервер для доверенной команды, а не изолированные арендаторы SaaS. Личная доска фильтруется по аккаунту.
- При смене провайдера переносится доступный контекст и краткая передача задачи. Скрытые рассуждения провайдера не переносятся. Восстановление контекста может расходовать дополнительные токены; нулевую разницу с нативным клиентом проект не обещает.
- Выполнение требует включённого подключённого компьютера. Телефон служит интерфейсом и не запускает локальные CLI.
- Лимиты и доступность моделей определяются вашим аккаунтом провайдера. Хостинг, хранение и внешние сервисы оплачиваются отдельно.
- Голос, MCP, скиллы и импорт могут требовать локальных компонентов. Начинайте с ручных разрешений и предоставляйте доступ осознанно.

## Разработка и публикация

```sh
npm run check
npm test
npm run audit:public
npm run site
```

Лендинг находится в `docs/` и публикуется через GitHub Pages. В демонстрации используются только вымышленные данные, запросы к рабочему хабу не выполняются.

Собственные обновления подписываются собственным ключом. Общего сервиса обновлений и телеметрии у Community-версии нет. Не публикуйте `.env`, базы, архивы подключения, журналы и собранные приложения с персональной конфигурацией.
