# Third-party components

The MIT license in this repository covers Team Room Community source. It does not relicense external products.

- Claude Code and Codex are separate products. Their names identify compatible providers. Their CLIs are obtained from official distributions when a user builds the desktop application; CLI binaries, subscriptions and credentials are not included in this repository. Each user signs in to their own account and remains subject to the provider's terms and limits.
- Manrope, Lora and JetBrains Mono font files are distributed under the SIL Open Font License. Full notices are retained beside the files in `public/fonts/`.
- JavaScript dependencies and their versions are listed in `package.json` and `package-lock.json`. Their own licenses remain applicable. No dependency directory is committed.
- The community window symbol is original artwork included under this repository's MIT license.
- This project is independently maintained; it is not an official application of either provider.
