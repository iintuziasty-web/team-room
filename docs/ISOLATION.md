# Изоляция установок

## Откуда берётся адрес

Веб-клиент обращается к собственному origin. Общая Mac-сборка запрашивает адрес своего HTTPS-хаба при первом запуске и сохраняет его отдельно от программы. Нативный iOS-клиент собирается с явно заданным адресом. HTTP разрешён только для loopback-разработки. У клиента нет резервного общего сервера.

Архив подключения создаёт ваш сервер. Он содержит случайный токен конкретного компьютера. Native helper принимает архив только того origin, который выбрал пользователь. Не раздавайте готовый архив подключения: это действующий ключ устройства.

## Что хранится отдельно

- Идентификатор native-приложения: `io.teamroom.community`.
- Фоновые агенты: `io.teamroom.community.connect.<случайный-id>`.
- Данные Mac: `~/Library/Application Support/Team Room Community Connect/`.
- Настройки Mac: `~/Library/Application Support/Team Room Community Desktop/`.
- Внешнее хранение: собственная папка `mac-offload/team-room-community-connect` на явно выбранном диске.
- Команда импорта: `teamroom-community`, без замены одноимённых команд других установок.
- Серверные cookies: `trc_session` и `trc_challenge`; токены и пароли создаются заново.
- Обновления: общий публичный канал раздаёт только код. Подпись и контрольная сумма проверяются локально, установка добровольная. Адрес своего хаба, пользователи, токены и файлы не отправляются в канал и не заменяются общим релизом.

В коде нет таблицы действующих устройств, пользователей, адресов развёртывания или ключей какой-либо готовой установки. Регистрация нового сервера не копирует старую базу.

## Граница обещания

Обычная установка не связывается с другим рабочим пространством автоматически. Подключение к какому-либо серверу требует явной настройки его адреса и действительных учётных данных. Изменённый сторонним человеком код или специально переданные ему credentials не могут быть ограничены этим репозиторием.

Принадлежность к GitHub-аккаунту обозначает владельца исходников, а не доступ к его серверу, подпискам или данным.

## Локальные провайдеры

Claude Code и Codex используют аккаунт того пользователя, который вошёл на выполняющем компьютере. Эти входы не поставляются в репозитории. Синхронизация MCP и скиллов в новом пространстве выключена и включается владельцем по своему решению. Импорт истории выполняется отдельным явным действием.
