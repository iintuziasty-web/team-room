## Автоматические сценарии

- Случайная приватная `.env` и сохранение существующей конфигурации.
- Обязательный токен первого владельца; отказ анонимному пользователю.
- Повторное создание владельца, вход по приглашению и настройки владельца.
- Отказ запросам с чужим Origin.
- Telegram-код: привязка к браузеру, срок действия, одноразовость.
- Личная доска другого аккаунта недоступна для изменения.
- Загрузка, HTML sandbox, byte ranges, отказ выходу из каталога.
- Исключение секретов, зависимостей и browser profiles из переносимых путей.
- Атомарная запись; запрет чтения/записи через ссылку за пределы рабочей папки.
- Архивация и восстановление простаивающего чата.
- Полный комплект подключения со своим токеном; обновление без device-config.
- Сохранение входа и чата после перезапуска хаба.
- Выход завершает browser WebSocket и делает cookie недействительной.
- Полнота пакета исходников iOS и проверки архива без Git-метаданных.

## Исправлено

Упаковка iOS ссылалась на отсутствующие файлы и не сохраняла относительную зависимость от общего модуля адреса хаба. Пакет исправлен, добавлены инструкция и лицензии. Удалена старая страница терминала без серверной реализации. Исправлена подсказка названий команд Community в архиве подключения. Добавлены повторяемые проверки, документация структуры и переноса. Compose требует явно указанный домен; минимальная версия Node.js уточнена под используемый флаг запуска.

## Что нельзя заявлять проверенным

Этот проход не является независимым пентестом или полной проверкой всех ветвей приложения. Не проверялись реальные задания Claude/Codex, прерывание длительной модели, нагрузка крупных проектов, полный подписанный universal Mac-релиз, Apple notarization и физический iPhone. Docker-образ нужно собрать и запустить в среде с Docker daemon. При обновлении официальных CLI совместимость проверяется снова.

Публичный продукт обозначен как **Community preview для самостоятельного размещения**. Пользователю нужны собственный хаб, хранилище и аккаунты провайдеров. Windows desktop installer и общий готовый сервис в выпуск не входят.


## Дополнение: канал обновлений 1.1.0

Добавлены проверки подписи Ed25519, SHA-256, разрешённых адресов загрузки, запрета отката версии, отказа во время активных задач, конкурентной подготовки, отключения проверок, сохранения адреса и базы при обновлении, возврата после сбоя запуска и восстановления прерванной установки. Проверяется, что устаревшая резервная копия не откатит более новые данные.

Общий Mac ZIP реально собран для arm64 и x86_64, проверен codesign; сборка ad-hoc, без Apple notarization. Раздел обновлений проверен в скрытом браузере на 1440 и 390 CSS px. Эта проверка не является испытанием установки на чужом физическом Mac.

Для подготовленного подписанного пакета доступна команда release:verify: настоящий хаб с синтетической предыдущей версией, новая установка зависимостей, замена процесса, сохранение входа, настроек и рабочего файла. Сами модели при этом не запускаются.
