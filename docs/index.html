Полная инструкция
  1. 1

    Запустите хаб

    Скачайте исходники и установите зависимости. Нужен Node.js 22.9 или новее.

  2. 2

    Создайте своё пространство

    Откройте localhost:4173. Код первого входа скрипт сохранит в вашем локальном .env.

  3. 3

    Подключите компьютер

    В разделе «Компьютеры» создайте своё подключение и войдите в аккаунт Claude или Codex.

Локальный запуск
git clone https://github.com/iintuziasty-web/team-room.git
cd team-room
npm ci
npm run setup
npm start
Затем откройте http://127.0.0.1:4173

Перед началом

Это бесплатное приложение?

Исходники доступны под MIT. Вы оплачиваете свой сервер, хранение и необходимые подписки провайдеров. Внешние сервисы и отдельные модели могут иметь собственные расходы.

Будет расходовать столько же токенов, сколько нативный клиент?

В рамках одного провайдера приложение использует его продолжаемую сессию. При смене провайдера, импорте или восстановлении требуется передать контекст. Это может добавлять расход токенов. Точного равенства с нативным приложением мы не обещаем.

Нужно оставлять рабочий компьютер включённым?

Да. Хаб хранит общее пространство, а модель и инструменты выполняются на выбранном компьютере. Телефон позволяет управлять ими и читать результаты.

Можно установить на iPhone?

Да: откройте свой HTTPS-хаб в Safari и добавьте на экран «Домой». Нативные исходники iOS тоже включены, но требуют самостоятельной сборки и подписи Apple.

С чем соединится моя установка?

С вашим собственным сервером и явно подключёнными сервисами. В коде нет готового общего хаба, аккаунтов или пар устройств. Общее Mac-приложение запрашивает адрес вашего хаба при первом запуске.

Это официальный клиент Claude или OpenAI?

Нет. Это независимое рабочее пространство, совместимое с официальными Claude Code и Codex. Каждый участник использует собственный доступ к провайдерам.

Как получать новые возможности?

В профиле откройте «Обновления Team Room»: описание, подготовка и установка по вашему решению. Сервер проверяет подпись релиза и не начинает установку во время активной работы. Mac обновляется отдельно через меню приложения; iPhone получает веб-часть с вашего хаба. Для старой версии 1.0.0 нужен однократный ручной переход.
